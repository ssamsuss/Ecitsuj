# Confidence Scale

Jurors report confidence as a number between 0.0 and 1.0:

- **0.0–0.3**: low confidence — significant unresolved doubt.
- **0.4–0.6**: moderate confidence — some doubt remains.
- **0.7–0.9**: high confidence — doubt is minimal but not eliminated.
- **1.0**: certainty — reserved for cases with no plausible alternative explanation.

This scale is shared across all jurisdictions to keep vote-shift and confidence metrics comparable between cases.
